# 📊 Retail Executive Summary Dashboard | Power BI

## 📌 Project Overview
This project focuses on analysing retail business performance using Microsoft Power BI. The Executive Summary Dashboard presents key performance indicators (KPIs) and interactive visualisations to help understand sales, transactions, and overall business performance.

Developed as part of my Data Analytics Fellowship at DataMelon Labs, this project helped me apply data analytics concepts and build practical business intelligence skills.

## 🎯 Objectives
- Monitor overall retail sales performance.
- Analyse transaction trends.
- Track key business performance indicators.
- Present business insights through interactive visualisations.
- Build an easy-to-understand executive-level dashboard.

## 📈 Dashboard Highlights
- **Total Sales:** Overview of overall sales performance.
- **Total Transactions:** Track the number of transactions.
- **Sales Analysis:** Explore sales performance and trends.
- **Performance Visualisation:** Present key metrics using charts and graphs.
- **Interactive Dashboard:** Explore data using available filters and visualisations.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Modelling
- Data Visualisation
- Business Intelligence

## 💡 Key Learnings
- Designing interactive dashboards in Power BI.
- Creating and analysing key performance indicators.
- Using data visualisations to communicate business performance.
- Presenting data in a clear and meaningful format.
